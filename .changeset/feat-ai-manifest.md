The package now ships machine-readable metadata for AI coding tools and other consumers. `@clickhouse/click-ui/ai/components.json` lists every public component with its import path, Storybook page, props (type, allowed values, default, description) and the design tokens it reads. `@clickhouse/click-ui/ai/tokens.json` lists every design token with its light and dark value. Both are generated from source on every release.

Visual: unchanged.
